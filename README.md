# JavaScript Quiz App

An interactive Quiz Application built using HTML, CSS, and Vanilla JavaScript.  
It simulates a real quiz experience with question navigation, state management, and dynamic score calculation.

---

## Project Purpose

Built to strengthen core frontend development skills including DOM manipulation, state management, and user interaction in JavaScript.

This project also demonstrates the ability to translate a UI design (Figma) into a fully functional and responsive web application.

---

## Key Features

- One-question-at-a-time quiz flow
- Navigation between previous and next questions
- Persistent answer selection when revisiting questions
- Real-time progress tracking
- Automatic score calculation
- Final results screen
- Ability to restart the quiz

---

## How It Works

- Questions are rendered dynamically from a JavaScript array
- Users select answers and navigate freely between questions
- Selected answers are stored and restored when revisiting questions
- Progress updates in real time
- Final score is calculated at the end of the quiz
